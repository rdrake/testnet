## Replace

This text:

```
- **A check that crashes abandons the rehash too.** If it dies of a fault (SIGSEGV, SIGBUS, an assert's SIGABRT and the like), the server's own parse of the same file would most likely crash the same way. Any other signal (SIGKILL from the OOM killer, SIGTERM from a stop) counts as not run.
- **A check that does not run fails open.** It says nothing about the file, so the rehash goes ahead as before, with a notice. What it printed, plus a last line saying how it ended (exit status, signal, or why it could not start), goes to the CONFIG log.
- **A check that does not finish in 10 s abandons the rehash**, and it is not tried again: the server's own parse might hang the same way.
```

There is no distinction between signals, and no retry inside the rehash: rehash again to try again.
