## Add at the end

```
**Changed after review (re-evaluation):** The value re-announce is back without the three hand-written hooks. `send_cap_notify()` given no value now sends the capability's stored value, the one CAP LS 302 lists, so the generic notify hook announces `evilnet.github.io/persistence` and `draft/persistence` with the extras' value when they are switched on. `PERSISTENCE_DRAFT_EXTRAS` sends `CAP NEW draft/persistence` with the new value (or the bare name once it has none) while the capability is offered. A side effect: `CAP NEW draft/metadata-2` carries its value too. Checked on a scratch server with `SET` and with `REHASH`; this branch has no CMocka harness for `m_cap.c` (the one in #283 can take a case once both are in).
```
